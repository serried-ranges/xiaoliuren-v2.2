# 数据兼容与迁移

> 状态：**已归档（2026-09-28）**，只读对照维护。  
> 定位：本文是 V2.2 **本地数据键名、导入导出与备份口径的唯一权威入口**（对应源码 `src/store/state.js`；2026-09-30 对照核对）。

## 本地存储键名

| 键 | 内容 |
|---|---|
| `xll_userId` | 本机身份 ID（自动生成，如 `u_xxx`；不按身份隔离） |
| `liuShenHistory_{身份ID}` | 当前身份的历史记录（JSON 数组） |
| `liuShenTemplates_{身份ID}` | 当前身份的 AI 提示词模板（JSON 对象） |
| `xll_divination_mode_{身份ID}` | 当前身份上次使用的排盘模式（字符串，默认 `gufa`；**每次打开会被重置为 `gufa`**，见[版本说明 §9](版本说明.md)） |
| `xll_ai_prompt_key` | AI 模板选择（字符串，默认 `gupai`；不按身份隔离，打开时随模式重置） |
| `xll_legacy_migrated_{身份ID}` | 旧数据迁移标记（**历史遗留：代码中只有清理逻辑，无写入**） |
| V2.1.2 旧键：`liuShenHistory` / `liuShenTemplates` / `xll_divination_mode` | **不会自动认领**；检测到仅输出控制台提示，需在旧页面导出后通过「导入」显式迁移 |

- 读取一律加兜底（`|| []`、`|| {}`、`|| 'gufa'`、`|| 'gupai'`），不得假设键一定存在；
- 身份隔离：首次使用自动生成身份 ID；不同身份的数据互不可见；同名身份在不同浏览器中数据独立。

## 历史记录结构（单条）

```json
{
  "id": "…",
  "timestamp": 0,
  "numbers": [1, 2, 3],
  "answers": [{ "step": 0, "shen": { "index": 0, "name": "大安", "cls": "da-an", "meaning": "…", "detail": "…" } }],
  "finalShen": { "index": 0, "name": "大安", "cls": "da-an", "meaning": "…", "detail": "…" },
  "question": "…",
  "method": "manual | time | random",
  "mode": "gufa | jiang | daochuan",
  "interpretation": "… 或 null",
  "feedback": { "rating": 1, "content": "…", "time": 0 } 
}
```

- `feedback` 为用户评分反馈（1–5 星 + 最多 500 字），可清除为 `null`；
- 同一三数 + 同一问念 + 同一终卦名的记录会合并更新（不重复入档）；
- 问念在保存时截断为 200 字，历史内编辑限 50 字。

## 导出格式

| 来源 | 结构 | 文件名 |
|---|---|---|
| V2.2 导出 | **纯数组** `[{…}]`（兼容只认数组的旧版本） | `liuShen_export_<YYYYMMDDHHmmss>.json` |
| V3.0 导出 | 信封 `{ version, history, customTemplates }` | 由 V3 决定 |
| V2.2.1 导出 | 信封 `{ version: "2.2", history }` | 由对应版本决定 |

## 导入兼容（按优先级）

1. V3.0 / V2.2.1 **信封**：读取 `history` 数组（`customTemplates` 仅记录，不导入）；
2. V2.0 结构：`{ records: [...] }` 或 `{ data: [...] }`；
3. 纯数组 `[{…}]`。

导入时的处理：

- 逐条校验 `numbers` / `answers` / `finalShen`，缺 `id` 自动补并计数，重复 `id` 跳过；
- `answers` 同时兼容 V2.2 嵌套结构 `{step, shen:{…}}` 与 V3.0 扁平结构 `{index, name, meaning, detail}`（V3 的 `index` 映射为 `step`）；
- `finalShen` 归一化为统一结构；保留 `question / method / mode / interpretation / feedback`；
- 导入后按 `timestamp` 降序排列，并 toast / alert 汇总新增与修复数量。

## 提示词模板格式

- 存储：`liuShenTemplates_{身份ID}` 对象 map（键为模板 id，值为 `{ id, name, text }`）；
- 导出：`{ app: "xiaoliuren-v2.2", type: "template", exportedAt: ISO 时间, templates: [{ id, name, isDefault, text }] }`，文件名 `template_<名称>_<时间>.json`；
- 导入：接受数组、`{ templates: [...] }` 或单个模板对象；模板名限 20 字；与默认模板 id 冲突时自动生成 `custom_…`；
- 默认模板不可删除；编辑默认模板会「另存为」新模板。

## 备份建议

- 导出为 JSON 文件并自行保管；导入前建议先导出当前数据；
- 清除浏览器数据或更换浏览器会丢失本地记录；服务端不保存任何内容。

## 与小红书离线版的关系

小红书版使用独立的存储命名空间与离线容器存储；两边的数据不会自动互通，跨端迁移只能通过用户主动导出 / 导入（若容器允许）。
