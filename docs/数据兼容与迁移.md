# 数据兼容与迁移

> 本文描述 V2.2 的本地数据口径；与 V3 的[架构与数据流](https://github.com/serried-ranges/xiaoliuren/blob/main/xiaoliuren-v3/docs/%E6%9E%B6%E6%9E%84%E4%B8%8E%E6%95%B0%E6%8D%AE%E6%B5%81.md)保持同一口径。

## 本地存储键名

| 键 | 内容 |
|---|---|
| `liuShenHistory_{身份ID}` | 当前身份的历史记录（JSON 数组） |
| `liuShenTemplates_{身份ID}` | 当前身份的 AI 提示词模板 |
| `liuShenHistory` / `liuShenTemplates` / `xll_divination_mode` | **V2.1.2 旧键**：不会自动认领；需在旧页面导出后通过「导入」显式迁移 |

- 身份隔离：首次使用自动生成身份 ID；不同身份的数据互不可见；同名身份在不同浏览器中数据独立。

## 导出格式

- **V2.2 导出**：纯数组 `[{...}]`（兼容旧 V2.2 只认数组的版本）；
- **V3.0 导出**：信封 `{ version, history, customTemplates }`；
- 两者互认：V2.2 可导入数组或信封；V3 可导入数组与信封（V2.2 格式），并额外提供「导出 V2.2 格式」。

## 字段转换（V3 → V2.2）

V3 记录中的 `{ index, name, meaning, detail }` 会在导入时转换为 V2.2 结构；未识别字段忽略，不覆盖现有记录。

## 备份建议

- 导出为 JSON 文件并自行保管；导入前建议先导出当前数据；
- 清除浏览器数据或更换浏览器会丢失本地记录；服务端不保存任何内容。

## 与小红书离线版的关系

小红书版使用独立的存储命名空间与离线容器存储；两边的数据不会自动互通，跨端迁移只能通过用户主动导出 / 导入（若容器允许）。
