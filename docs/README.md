# docs 目录：开发事实与说明

> 本目录是面向维护者的**当前代码事实、结构与操作说明**（对应主项目 `xiaoliuren/docs/`）。
> 治理、产品与质量资料见 [文档/](../文档/README.md)；历史资料见 [history/](../history/README.md)；接手请从[文档/治理/接手与重启.md](../文档/治理/接手与重启.md)开始。

## 1. 本目录文档

| 文档 | 回答什么 | 唯一权威范围 |
|---|---|---|
| [版本说明](版本说明.md) | 当前版本是什么、有哪些功能与文件、测试数字 | 版本事实、文件清单、数字口径 |
| [开发者指南](开发者指南.md) | 怎么开发、模块如何加载、怎么构建与排错 | 源码结构、加载顺序、命令、排错 |
| [数据兼容与迁移](数据兼容与迁移.md) | 数据存在哪、导入导出什么格式、怎么备份 | 存储键名、导入导出、备份口径 |
| [使用说明_V2.2.md](使用说明_V2.2.md) | 使用者怎么起卦、排盘、记录与导出 | 面向使用者的操作说明 |

## 2. 阅读顺序

1. 接手 / 重启 → [文档/治理/接手与重启.md](../文档/治理/接手与重启.md)
2. 了解现状 → [版本说明](版本说明.md)（历史差异与修复见 §9）
3. 改代码 → [开发者指南](开发者指南.md)
4. 碰数据 → [数据兼容与迁移](数据兼容与迁移.md)

## 3. 维护规则

- 本目录只写当前代码事实与操作；方向、历史与账本放 [文档/](../文档/README.md)；
- 同一事实只保留一个权威入口（地图见[接手与重启 §3](../文档/治理/接手与重启.md)）；
- 数字以命令输出为准，快照标注实测日期；数字变化时同步[版本说明](版本说明.md)与[根 README](../README.md)；
- 移动 / 重命名文档后运行 `npm run check:docs`；
- 文档只描述本仓库事实，跨项目引用使用绝对链接。
