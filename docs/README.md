## 维护规则

- 文档只描述本仓库事实；跨项目内容使用绝对链接指向对应仓库，不写跨仓相对路径；
- 同一事实只保留一个权威入口；数字改动时同步 [README](../README.md) 与[版本说明](版本说明.md)；
- 归档期内只随安全 / 正确性修复更新文档，不新增功能说明；
- 移动 / 重命名文档后运行 `npm run check:docs`（CI 也会检查），确保没有死链。
