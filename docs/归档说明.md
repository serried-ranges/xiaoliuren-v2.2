# 归档说明

> 状态：**已归档（2026-09-28）**。本仓库只读对照使用，不再作为开发入口。

## 定位

V2.2 是 V3 之前的「简洁版」与历史兼容基线：保留旧版行为、排盘结果与备份格式，供以下用途：

- 核对旧版排盘结果与行为差异；
- 验证旧数据（localStorage 键名、导出格式）的兼容与迁移；
- 作为三项目（V3 / V2.2 / 小红书版）排盘知识一致性的人工对照。

## 维护边界

- ✅ 接受：正确性修复、安全与隐私修复、浏览器兼容与可访问性修复、测试与文档补充；
- ❌ 不接受：新功能、新皮肤、新入口、依赖升级类重构；
- 不跟进 V3 的功能与视觉；跨项目迁移必须走主项目的「功能迁移单」流程。

## 与另外两个项目的关系

| 项目 | 关系 |
|---|---|
| V3（主项目） | 唯一活跃开发与网页发布源；V2.2 只做兼容核对，不反向同步 |
| 小红书离线版 | 独立仓库；两者共享排盘知识与设计原则，不共享构建时源码 |

## 如需恢复活跃

先明确维护者与范围，更新本说明与 [CONTRIBUTING](../CONTRIBUTING.md)，并补齐 CI 与真机 / 浏览器验收记录；在此之前保持归档状态。

> GitHub 仓库可在 Settings → Archive this repository 标记为只读（人工操作项）。
