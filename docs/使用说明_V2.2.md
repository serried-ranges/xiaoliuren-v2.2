# 小六壬排盘 V2.2 使用说明

> 适用版本：V2.2.0 · 简洁离线排盘工具  
> 状态：**已归档（2026-09-28）**，面向使用者的操作说明；对应交付物 `dist/index.html`。  
> 历史差异与修复记录见[版本说明 §9](版本说明.md)。

## 1. 开始使用

推荐打开 `dist/index.html`（明码单文件），双击即可运行，无需安装或联网。

首次使用浏览器可能要求允许本地文件保存数据。若 localStorage 被禁用，排盘仍可用，但历史记录和模板无法长期保存。

V2.2 自动为每个用户生成独立身份 ID，历史记录和模板按身份隔离存储。

## 2. 排盘操作

1. 输入问念（最多 200 字）；
2. 选择取数方式：手动输入 / 时间起卦 / 随机起卦；
   - **时间起卦**：取当前时间——小时 0 记 10、超过 12 减 12，分钟十位与个位分别作为后两数、为 0 时记 10；
   - **随机起卦**：生成 1–999 的三个随机数；
3. 点击「开始推算」查看结果；
4. 点击「重置」重新开始。

建议一次只问一件事。结果仅供文化娱乐参考。

## 3. 排盘模式

| 模式 | 入口 | 输出 |
|------|------|------|
| 古法 | 默认 | 三宫与终落宫简明结果 |
| 江氏 | 进阶排盘 | 地支/六亲/六神/六星（六宫全貌） |
| 道传 | 进阶排盘 → 道传标签 | 死活六神双轨 + 排盘表 |

**注意**：三种模式共用同一组三数，切换不重新起卦；**刷新页面后保持上次选择的模式**（默认古法）。

## 4. AI 解析与模板

完成排盘后点击「🤖 AI解析」，工具生成与当前模式匹配的提示词，可复制到你选择的 AI 服务使用。本工具不自动向第三方发送数据。

模板操作：切换默认模板 / 新建编辑 / 导入导出 JSON / 复制提示词。模板名最多 20 字；导入前建议先备份。

## 5. 历史与备份

- 点击「📜 记录」查看历史，可回载、编辑问念（最多 50 字）、删除、清空；
- 每条记录可填 1–5 星反馈与最多 500 字的说明；
- 「导出」下载 JSON 备份（文件名 `liuShen_export_<时间>.json`），「导入」恢复数据——兼容 V2.2 数组与 V3.0 信封格式；
- **导入他人分享的 JSON 前请确认来源**：记录内容会原样显示在页面上（已做 HTML 转义，不会执行脚本），但仍不建议导入来路不明的文件。

## 6. 更多功能

- 结果区下方「📚 知识速查」：六宫/六亲/六神/六星说明；
- 右上角「☰ 更多」：
  - 导出卦例 / 导入卦例；
  - 切换标准：跳转到正式站点 `x6ren.cn`（需联网）；
  - 鸣谢名单 / 联系作者（点击邮箱即可复制）/ 赞助支持。

## 7. 常见问题

- **无历史记录**：检查浏览器是否允许本地存储；
- **导入失败**：确认是 JSON 文件，先备份再导入；
- **白屏或样式缺失**：使用 `dist/index.html`，不要只复制单个文件。

## 8. 边界与免责

- 纯本地应用：不发起网络请求、不收集或上传数据；唯一外跳为「更多 → 切换标准」；
- 排盘与解读内容仅为传统民俗参考，不构成任何预测或决策依据；
- 重要记录请主动导出备份。
