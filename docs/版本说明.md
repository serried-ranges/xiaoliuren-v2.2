> 状态：**已归档（2026-09-28）**，只读对照维护；维护边界见[归档说明](../归档说明.md)，接手与重启见[文档/治理/接手与重启.md](../文档/治理/接手与重启.md)。

## 1. 版本概述

V2.2 是 V2.1.2 的工程化拆分版，将单 HTML 拆分为 12 个 JS 子模块 + 4 个 CSS 文件；**与 V2.1.2 的行为差异见 §9**。

### 核心变更

| 变更 | 说明 |
|------|------|
| 模块化拆分 | 单 HTML → 外链 `<script>` × 12 + CSS × 4 |
| 道传小六壬 | 死活六神双轨 + 隔位地支排法（代码中无「四纵五横」实现） |
| AI 提示词 | 3 套强约束模板（古法/江氏/道传） |
| 项目独立 | 不再依赖 serverless，所有核心模块本地化 |
| 问念限制 | 200 字上限 |
| 更多菜单 | 导出卦例 / 导入卦例 / 切换标准（跳转 `x6ren.cn`）/ 鸣谢名单 / 联系作者 / 赞助支持 |
| 精简功能 | 移除收藏夹、时空八字、六十四卦 |

## 2. 功能特性

| 功能 | 说明 |
|------|------|
| 古法排盘 | 三数 → 掌诀定位 → 天/地/人三宫与终落宫 |
| 江氏小六壬 | 三宫 + 时辰 → 地支/六亲/六神/六星（六宫全貌） |
| 道传小六壬 | 死活六神双轨 + 隔位地支（天地人三宫） |
| 起卦方式 | 手动输入 / 时间起卦 / 随机起卦（`Math.random`，无网络） |

| 解卦反馈 | 1-5 星准确度评分 + 最多 500 字反馈 |
| 历史记录 | 保存/回载/编辑/删除/清空；JSON 导入/导出（跨设备备份），兼容 V3.0 信封格式 |

| 知识速查 | 结果区折叠面板：六宫/六亲/六神/六星说明 |

## 3. 交付物

| 产物 | 命令 | 说明 | 大小（2026-10-01 实测） |
|------|------|------|------|
| `dist/index.html` | `npm run build` | 明码单文件，双击即用；**可由源码逐字节复现** | 734,090 字节 |
| `release/index.html` | `npm run build:protected` | 混淆保护版；**每次构建字节不同（混淆随机），不要用哈希比对**，验证用 `npm run test:protected` | 941,096 字节（2026-10-01 构建；大小可能浮动） |

> 「受保护」只提高源码阅读门槛，**不是**密钥保护或保密方案；前端不放置任何密钥。

## 5. 架构概览

- 分层：`src/core/`（算法）→ `src/store/`（状态与存储）→ `src/ui/`（渲染与事件）＋ `src/utils/`（工具）；
- 12 个模块通过 `<script>` 顺序加载、共享 Script scope（非 ES Module），`file://` 协议直接可用；
- **运行时覆盖**：`domain-adapter.js` 启动时用 `browser-core.js` 的实现覆盖 `calculator.js` 的同名函数（`calculate / generateJiangPai / generateDaoPai / generateJieGua / generateDaoJieGuaText`）——页面实际计算以 `browser-core.js` 为准；
- 分层细节、加载顺序与差异说明以[开发者指南](开发者指南.md)为权威，本文不再重复。
