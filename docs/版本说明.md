# 小六壬排盘 V2.2 — 版本说明

> 状态：**已归档（2026-09-28）**，只读对照维护；维护边界见[归档说明](归档说明.md)，接手与重启见[重启与接手指南](重启与接手指南.md)。  
> 定位：本文是**版本事实的唯一权威入口**——功能、交付物、文件清单与测试数字均以本文为准（数字标注实测日期，最终以命令输出为准）。  
> 版本：V2.2.0 · 架构：外链 Script 标签模块化（共享 Script scope，`file://` 直接可用）  
> 交付物：`dist/index.html`（明码单文件）+ `release/index.html`（混淆保护版）

---

## 1. 版本概述

V2.2 是 V2.1.2 的工程化拆分版，将单 HTML 拆分为 12 个 JS 子模块 + 4 个 CSS 文件，保留 V2.1.2 所有样式与功能 100% 不变。

### 核心变更

| 变更 | 说明 |
|------|------|
| 模块化拆分 | 单 HTML → 外链 `<script>` × 12 + CSS × 4 |
| 道传小六壬 | 死活六神双轨合参排盘 |
| AI 提示词 | 3 套强约束模板（古法/江氏/道传） |
| 项目独立 | 不再依赖 serverless，所有核心模块本地化 |
| 问念限制 | 200 字上限 |
| 更多菜单 | 鸣谢/联系/打赏 |
| 精简功能 | 移除收藏夹、时空八字、六十四卦 |

## 2. 功能特性

| 功能 | 说明 |
|------|------|
| 古法排盘 | 三数 → 掌诀定位 → 天/地/人三宫 |
| 江氏小六壬 | 三宫 + 时辰 → 地支/六亲/六神/六星 |

| 用户隔离 | 自动用户 ID + 数据命名空间隔离 |

---

## 3. 交付物

| 产物 | 命令 | 说明 | 大小（2026-09-30 实测） |
|------|------|------|------|
| `dist/index.html` | `npm run build` | 明码单文件，双击即用；**可由源码逐字节复现** | 约 719 KB |
| `release/index.html` | `npm run build:protected` | 混淆保护版；**每次构建字节不同（混淆随机），不要用哈希比对**，验证用 `npm run test:protected` | 约 939 KB |

> 「受保护」只提高源码阅读门槛，**不是**密钥保护或保密方案；前端不放置任何密钥。

## 5. 架构概览

- 分层：`src/core/`（纯算法，不访问 DOM/localStorage）→ `src/store/`（状态与存储）→ `src/ui/`（渲染与事件）＋ `src/utils/`（无业务纯工具）；
- 12 个模块通过 `<script>` 顺序加载、共享 Script scope（非 ES Module），`file://` 协议直接可用；
- 分层约束、模块清单与加载顺序以[开发者指南 §1–§3](DEVELOPER_GUIDE_V2.2.0.md)为权威，本文不再重复。
