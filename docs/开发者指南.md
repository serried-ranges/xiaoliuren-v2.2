# 小六壬 V2.2.0 开发指南

> 状态：**已归档（2026-09-28）**，只读对照维护；本文是源码结构、加载顺序、构建 / 测试命令与排错的**唯一权威入口**。  
> 交付物：`dist/index.html`（明码）+ `release/index.html`（混淆保护版）  
> 环境要求：Node.js ≥ 14 LTS 可运行脚本；CI 与推荐环境为 Node.js 22（见 `.github/workflows/ci.yml`）

## 2. 分层职责（现状）

| 层 | 目录 | 主要做什么 | 约束 |
|----|------|--------|---------|
| 算法层 | `src/core/` | 排盘、取余/行步、农历转换；数据表 | 以纯函数为主；**例外**：`calculator.js` 的两个「排盘逻辑详情」弹窗函数直接操作 DOM |
| 状态层 | `src/store/` | 状态变量、CRUD、safeLS、导入导出 | 不拼业务 HTML；**现状**：含少量 DOM 引用与 classList 绑定（问念计数、知识速查折叠） |
| 表现层 | `src/ui/` | 渲染 DOM、绑定事件、弹窗 | 不新增算法与持久化格式 |
| 工具层 | `src/utils/` | Toast / 复制 / HTML 转义等纯工具 | 不含领域知识 |

> 以上「例外」为历史遗留；新增代码不要扩大它们。

## 3. 加载顺序与运行时覆盖（重要）

### 3.1 加载顺序（`index.html` 底部，顺序不可变）

```
1. lunar.js             无依赖
2. calculator.js        排盘实现（随后被覆盖）
3. browser-core.js      公共领域核心（实际计算实现）
4. domain-adapter.js    用 browser-core 覆盖 calculate / generateJiangPai /
                        generateDaoPai / generateJieGua / generateDaoJieGuaText
5. canonical-prompt.js  统一提示词
6. state.js             依赖 document
7. dom.js               依赖 state.js
8. template.js          依赖 state.js
9. feedback.js          依赖 state.js
10. more.js             依赖 state.js
11. renderer.js         依赖计算函数/state/dom/template
12. main.js             入口，依赖以上全部
```

### 3.2 运行时覆盖说明

- 页面**实际使用** `browser-core.js` 的实现；`calculator.js` 的同名函数在启动后被 `domain-adapter.js` 静默覆盖；
- 只修改 `calculator.js` 不会改变页面行为；修改算法请改 `browser-core.js`（或先调整覆盖关系，并同步测试）；
- 两套实现的数据口径已于 2026-10-01 统一（空亡释义「谋事落空，徒劳无功」、六星命名、道传解卦长版文本），运行时与 `calculator.js` / 知识速查 / 测试副本一致；修改任一处时必须同步其余副本（进度见[待办事项与方案进度](../文档/治理/待办事项与方案进度.md)）。

## 4. 日常开发流程

### 4.1 改代码

| 需求 | 改哪个文件 |
|------|-----------|
| 新增面板/按钮 | `index.html` + `main.js` |
| 改排盘算法 | `src/core/browser-core.js`（运行时入口） |
| 修改样式 | `styles/base.css`（其余为占位） |
| 替换联系方式 | `more.js` 常量 |
| 新增子模块 | 同步改 `index.html` + `package.json` 的 `check`（见 §7） |

### 4.2 语法检查

```powershell
npm run check
```

无输出即通过。任何 `SyntaxError` 必须在此阶段修复。

### 4.3 测试

```powershell
npm run test:all        # 5 个核心脚本（2026-10-03 复跑 579 项断言全部通过）
npm run test:compat     # V2.2 ↔ V3.0 数据兼容（144 用例）
npm run test:protected  # 受保护发布包检查（8 条断言）
npm run check:docs      # 文档相对链接检查
```

注意：除 `test-v22-lunar.mjs` 第【6】节直接加载 `src/core/lunar.js` 验证真实农历转换外，其余测试均为自包含逻辑副本，不导入运行时模块，**可能发生漂移；它们只提供规则回归参考，不代表真实页面或打包产物的完整行为验收**；覆盖范围详见[契约测试清单](../文档/质量与审计/契约测试清单.md)。页面行为按 §4.5 双击产物人工检查。

### 4.4 构建

```powershell
# 明码版本（dist/index.html，可由源码逐字节复现）
npm run build

# 混淆保护版（release/index.html）
npm run build:protected

# 验证保护版
npm run test:protected
```

> 注意：受保护构建**每次输出字节不同**（混淆器带随机性，产物大小可能小幅浮动）；重建后 `release/index.html` 在 `git status` 中显示变更属正常现象，不要用哈希或 `git diff` 判断发布包新旧，验证一律使用 `npm run test:protected`。

### 4.5 验证清单

双击打开 `dist/index.html`（`file://` 直开），依次检查：

1. 古法排盘（1/2/3）正常；
2. 进阶排盘：江氏、道传三盘与表格正常；
3. 历史记录 + 模式标记；
4. AI 模板三套默认可用，复制提示词正常；
5. 知识速查折叠正常；
6. 更多菜单：导出/导入卦例、鸣谢、联系、赞助正常；「切换标准」跳转 `x6ren.cn`；
7. 控制台无 JS 错误（历史差异见[版本说明 §9](版本说明.md)）；
8. 刷新页面后保持上次排盘模式（江氏 / 道传 / 古法均验证一次）；
9. **导入安全**：用一份问念含 HTML 标签/引号的 JSON 测试（如 `<img src=x onerror=alert(1)>`），历史列表与结果区应原样显示文本，无弹窗、无脚本执行。

## 5. 构建原理

### 5.1 build-single.cjs（明码版）

- 读取 `index.html`，用正则匹配 `<link rel="stylesheet">` 与 `<script src>`；
- 读取对应文件并内联为 `<style>` / `<script>`（脚本内含字面量 `</script>` 时自动转义）；
- 缺失 CSS/JS 时立即报错退出；默认输出 `dist/index.html`，`--out` 路径必须位于仓库内。

### 5.2 build-protected.cjs（混淆保护版）

1. 调用 `build-single.cjs --out release/index.raw.html` 生成原始单文件；
2. 提取全部内联 `<script>`（含预检脚本）合并；
3. 用 `javascript-obfuscator` 混淆（变量十六进制 + 字符串 base64），再 XOR + base64 封装；
4. 生成 loader 注入 `</body>` 前，输出 `release/index.html` 并删除 `index.raw.html`；
5. 注意：若保护阶段抛错，明文中间文件 `release/index.raw.html` 可能残留，需要手工清理。

## 7. 新增子模块

必须同步修改：

1. **`index.html`**：在正确位置插入 `<script src="...">`（顺序见 §3，不能破坏依赖链）；
2. **`package.json`**：`scripts.check` 追加 `&& node --check src/...`。

## 8. 排错速查

| 症状 | 原因 | 解决 |
|------|------|------|
| `xxx is not defined` | 加载顺序错误 | 对照 §3 检查 `<script>` 顺序 |
| 改了 `calculator.js` 但页面无变化 | 运行时被 `browser-core.js` 覆盖 | 修改 `src/core/browser-core.js`，或调整覆盖关系 |
| 改数据后页面/知识速查不一致 | 数据副本需与运行时同步 | 同时更新 `src/core/browser-core.js`（运行时口径）与测试副本 |
| 改源码后 dist 不变 | 未重新构建 | 执行 `npm run build` |
| 切换模式后渲染错误 | `switchDivinationMode` 参数错误 | 确认 `silent=false` |
| 新增 JS 不生效 | 未在 index.html 登记 | 按 §7 同步修改 |
| 打包报错 | CSS/JS 路径不对 | 确保使用相对路径 |
| 文档检查失败 | 移动/重命名文档后链接失效 | 运行 `npm run check:docs`，按提示修正相对路径 |
| 受保护包测试失败 | 构建失败或产物被手工编辑 | 重新 `npm run build:protected` 并保持产物不入手工修改 |

## 9. 最小可工作包

换电脑 / 换 IDE 只需带这些文件：

- `index.html` + `styles/` + `src/`；
- `build-single.cjs` + `scripts/`；
- `package.json`（可选）。

不需要：`node_modules/`、`vite.config.js`、`docs/`、`文档/`、`history/`、`dist/`、`release/`（后两者可重新构建）。
