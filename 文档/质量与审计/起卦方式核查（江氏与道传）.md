## 二、起卦方式逐项核查

### 2.1 江氏起课：本地三数模型 vs 官方两宫模型

- **官方口径**（教程 9、官方 V2.0"四法起课"）：核心是「A 宫 → B 宫」——
  - 日时法：大安起日数得 **A 宫（日宫）**，日宫起时辰数得 **B 宫（身宫，身宫地支＝时辰地支）**；
  - 时刻法：时辰定宫后按"刻"续数（10 分钟一刻）；
  - 数字法：报数取余定宫，再按时辰续数。
- **本地实现**：统一「三数递进」——`天宫＝大安起 n1`、`地宫＝天宫起 n2`、`人宫＝地宫起 n3`（数字起卦与时间起卦共用同一条链路）。
- **映射关系**：本地未显式区分 A/B 宫，但装卦时以**人宫＝身宫**、**天宫＝A 宫（第一落宫）**处理。本次修正（地支／六神／六星）即按此映射对齐官方规则。
- **说明**：本地是"三数合一"的产品化改编，不等价于官方任一单法；用官方日时法起课请手动输入对应三数（日数及两段续数）。

### 2.2 道传起卦：数字法等价、时间法为产品约定

- **数字法**：设三数为 n1、n2、n3，skill 算法为
  `天＝n1%6`、`地＝(天+n2-1)%6`、`人＝(地+n3-1)%6`（值 0=空亡、1=大安…5=小吉）。
  本地行步算法为 `下一宫＝(当前宫+步数-1) mod 6`（余数 0 按 6）。**经逐式推导，n≥1 时两者完全等价**（示例：(3,5,7) 两法均得 速喜→大安→大安）；仅 0 的处理不同（§2.3）。
- **时间法**：skill 用「农历月＋农历日＋时辰序号」代入同一三数公式；本地时间起卦用「小时（>12 减 12）＋分钟十位＋分钟个位」。
  - 本地口径是产品工程约定（`文档/产品/小六壬历史文化与排盘方法.md` §2 已声明，且不宣传为古法标准）；
  - **变通路径**：按 skill 口径起课可手动输入「月、日、时辰序号」（例：正月初五卯时 → 1、5、4），结果与 skill 时间法一致（已用 examples.md 示例 7 复核）。
- **地支隔位**：skill 排盘**不含**地支；本地"以人宫时辰为基准、顺时针隔位相排"源自 V3 迁移，属本地扩展。本次核查保留该实现，并在文档中标注其非 skill 规范。

### 2.3 报数 0（与负数）的处理差异

- skill：`若 num == 0，则视为 10`（0→10，接入 `+n-1` 公式）；
- 本地：`余数＝n%6，为 0 按 6 处理`（0 与 6、12 等效）；
- 本地"0 按 6"为**已确认保持现状**的产品决策（《待办事项与方案进度》）；本次**不做修改**，仅记录：使用 skill 口径时请以 10 代替 0（或避免输入 0）。
- 负数：本地按绝对值处理；skill 未定义负数。属本地输入容错。

## 三、江氏装卦修正说明（本次已实施）

1. **排地支（自身宫起）**：`diZhiMap[宫i]＝dzList[(pos(时辰) + (i - idx(人宫)) + 12) % 6]`——人宫落时辰地支，隔位相排。复核例（官方演示）：戌时、人宫赤口 → 赤口戌、小吉子、空亡寅、大安辰、留连午、速喜申（与官方教程演示一致）。
2. **排六神（起点表）**：`神(宫i)＝[青龙,朱雀,勾陈,白虎,玄武,腾蛇][(i - start + 6) % 6]`，`start` 由身宫地支查表（子/午→大安，丑/未→留连，寅/申→速喜，卯/酉→赤口，辰/戌→小吉，巳/亥→空亡）。与官方 V2.0「六神起始位置表」12 行逐行核对一致。
3. **排六星（A 宫起）**：`星(宫i)＝[木星,火星,土星,金星,水星,天星][(i - A + 6) % 6]`，`A＝天宫（第一落宫）`。与官方「五星排列表」逐行核对一致。

## 四、遗留差异与建议（未实施）

### 4.1 江氏六亲：生克直推 vs 官方查表
- 官方 V2.0 为**预生成六亲表**（身宫地支 × 宫地支），含「非土身宫时土支分别记兄弟／官鬼」的体系特例（例：身宫子水，官方表丑／辰／未＝兄弟、戌＝官鬼；生克直推会得官鬼）。
- 影响：仅非土身宫且相关宫落"土支"时结果不同。
- 建议：后续如需完全对齐官方，需内置 12×12 六亲表并同步更新文档与测试（属数据表引入，非本次小修范围）。

### 4.2 道传专用时间起卦（月/日/时辰）
- 现状：时间起卦对所有模式生效同一条"小时＋分钟"链路，无法按模式区分。
- 建议：若需完全对齐 skill 时间法，可新增「道传时间输入」入口（月／日／时辰序号三输入），或保持"手动输入变通路径"（当前已可用）。

### 4.3 宫位直选法
- skill 支持「宫位直选」（直接指定天／地／人三宫）；本地仅数字／时间／随机。可作为后续增强项（需 UI 与数据模型配合）。

### 4.4 六步解卦法的输出强化
- skill 给出六步解卦框架；本地已在其础上把「体用＋三宫角色＋六步提示」写入道传 AI 提示词（本次已实施，见优化方案文档），后续可再按需细化。

## 六、宫位结构专题：两宫 vs 三宫（2026-10-05 补充）

> 背景：对照 [x6ren.com](https://x6ren.com/)（v2.2「切换标准」跳转站）与 [xiao6ren.com/i](https://www.xiao6ren.com/i)（道传站）后，确认各体系的宫位结构差异与本地适配口径。

### 6.1 各体系宫位结构（实证）

| 体系 | 宫位结构 | 证据 |
|---|---|---|
| 官方江氏 V2.0 | **两落点**：A 宫（日／报数）→ B 宫＝身宫（时宫） | 装卦九步 A/B 框架；日时法「大安起日、日上起时」（不用月） |
| x6ren.com（**象数小六壬**，非江氏） | **两宫**：日宫＋时宫（自身宫） | 页面文案：「只取『数』与『起课时辰』两个信息」；「盘面上会标出日宫与时宫……这两宫通常是看盘的重点」；站点 JS：`起课数字→日宫`、`自身宫（时宫）`；全站无「三宫／天宫／地宫／人宫」 |
| xiao6ren.com/i（道传） | **三宫**：天宫／地宫／人宫(体)＋时辰(用) | 排盘表头；起卦三法（数字＝三个数字、宫位＝三宫直选、时间＝月·日·时辰） |
| 传统／古法 | **三宫**：月宫→日宫→时宫 | 传统月日时三段落宫 |

> ⚠️ **重要澄清**：**x6ren.com 不是江氏体系**——其代码中「江氏／江式」出现 0 次，自称「象数小六壬」，采用自家五行（**留连火、速喜阳土、空亡阴土**），与官方江氏（留恋水、小吉木）、道传（留连土、小吉水）均不同。「对齐 x6ren」与「对齐官方江氏」不能同时成立；本项目以**官方江氏 V2.0** 为江氏基准，x6ren 仅作界面级对照（「切换标准」跳转），不并入江氏算法。

### 6.2 结论：三宫法适用性

| 体系 | 三宫法 | 原因 |
|---|---|---|
| **道传** | ✅ 适用且必需 | 三数落三宫＝起因／经过／结果；人宫＝体、时辰＝用；缺一宫则「三宫合参」「体用」无法成立 |
| **江氏（官方 V2.0）** | ❌ 非其结构 | 只需「一个取数＋时辰」：数→A 宫；A 宫起时辰→身宫（时宫）。第二落点由时间承担，无第三落点职能 |
| **传统／古法** | ✅ 适用 | 月→日→时三段落宫（三宫法的出处） |
| x6ren 象数 | ❌ 非其结构 | 与江氏同机制：取数→日宫；日宫起时辰→时宫（自身宫） |

### 6.3 本地适配口径声明

- 本地为**统一三数引擎**：第一数→天宫、第二数→地宫、第三数→人宫（逐段递进）；三种取数方式（手动／时间／随机）共用；
- 江氏模式以**第三落点（人宫）**作为「自身宫（身宫）」适配位：身宫地支＝起课时辰地支；排地支自人宫起、六神按身宫地支查起点表、六亲以人宫地支五行为我、六星自第一落点（A 宫适配位）起木星（2026-10-05 修正后口径）；
- 该适配在「第三落点恰为 A 宫起时辰的续数落宫」时与官方完全相同；其余情况为**本地产品约定**（不是官方口径，也不应宣传为官方日时法）；
- 若要严格复现官方日时法（两落点：取数→A 宫，A 宫起时辰→身宫），本地尚未提供专用入口——已列入后续可选评估（见《待办事项与方案进度》）。

### 6.4 为什么不把 x6ren 并进来

- x6ren 属**象数小六壬**（自有一套五行与断法），与江氏、道传并列而不相属；
- 若需该体验，应**另立「象数」模式**（新版本／新分支），而不是替换江氏——「一模式对一权威」，避免口径互相污染。
