# 小六壬历史文化与排盘方法

> 更新时间：2026-09-30
> 适用范围：V2.2 当前排盘实现与解读边界
> 文档性质：传统文化与软件规则说明，**不是**预测准确性证明，也不构成医疗、法律、投资或其他专业意见

## 先说结论

小六壬适合被理解为一种**轻量、快速、以当下问题为中心的民俗推演方法**。它的价值在于把「什么时候问、问什么、如何记录、后来如何验证」整理成一条可回看的思考路径；局限也很明确：信息维度少、流派口径差异大、解释容易受提问方式影响，不能替代现实中的证据与专业判断。

V2.2 在同一组三数上提供三种观察视图：

1. **古法（基础三宫）**：三数依次落入六宫，显示天宫、地宫、人宫与终落宫；
2. **江氏**：展开六宫、地支、五行、六亲、六神、六星；
3. **道传**：展开天地人三宫、地支、六亲与死活六神双轨。

三种视图不是三次起卦，也不表示其中必有一个「最准确」。

## 一、历史文化：先分清「六壬」与「小六壬」

- **六壬**：传统术数中以干支、五行、天地盘、神将、四课、三传等要素组织的占课体系，文献多、传承杂。清代《四库全书》所收《六壬大全》把六壬与遁甲、太乙并称「三式」，同时指出历代分歧；明代《六壬集应钤》是现存文献研究中常被提到的材料。这些说明「六壬」是一条长期文献脉络，**不能**直接证明今天所有「小六壬」口诀出自同一传承。
- **小六壬**：更接近民间便捷化的称呼。中国台湾教育部《重编国语辞典修订本》解释为：将「大安、留连、速喜、赤口、小吉、空亡」六位分置于手指，以月、日、时轮数求得结果，也称「报时起课法」。这能说明基本文化形态，但不能替所有现代流派确认唯一算法。
- 民间常把「小六壬」与袁天罡、李淳风、马前课、《玉匣记》等联系起来；这些叙事有文化传播价值，但人物归属与成书年代不能仅凭网络转引当作定论。

本项目采用三层标注，避免把叙事、整理与实现混为一谈：

| 层次 | 可以怎样说 | 不应怎样说 |
|---|---|---|
| 可核查文献 | 某辞典或古籍记录了某种称呼、术语或方法 | 由一条记载推出所有现代算法同源 |
| 民间传承与现代整理 | 某作者或教材自述采用某种规则 | 把自述写成学界已证实的唯一源流 |
| 本项目实现 | V2.2 代码采用何种输入、映射与显示规则 | 把软件实现包装成古代原貌或科学结论 |

## 二、流派比较（按规则结构）

| 类型 | 常见结构 | 本项目关系 |
|---|---|---|
| 基础三宫 / 常见小六壬 | 三数依次落入六宫，看天、地、人关系 | 作为「古法」基础视图 |
| 加时或四宫扩展 | 三宫之外纳入时辰或时间条件 | 作为江氏、道传的时间输入基础 |
| 六宫综合类 | 以六宫为完整表面，叠加地支、五行、六亲等 | 当前「江氏」排盘 |
| 死活六神 / 天地人合参类 | 兼看固定宫神与随时辰轮转的神 | 当前「道传」排盘 |
| 九宫 / 八卦扩展类 | 加入洛书九宫、八卦或奇门元素 | 当前不纳入：缺少可稳定核验的统一定义 |

选择多种视图的前提是：**输入一致、规则透明、结果可复现、解释不越界**。V2.2 不提供更多流派按钮，是因为「多」不等于「全」或「准」。

## 三、V2.2 当前排盘规则

以下描述的是本仓库源码当前实现，不宣称代表所有小六壬流派；已知的运行时差异见[待办事项与方案进度](../治理/待办事项与方案进度.md)。

### 1. 三数与六宫

| 索引 | 宫位 | 五行 | 基础取象（运行时终卦结果） |
|---:|---|---|---|
| 0 | 大安 | 木 | 平安吉祥，诸事顺利 |
| 1 | 留连 | 土 | 事有拖延，需耐心等待 |
| 2 | 速喜 | 火 | 喜事临门，快速达成 |
| 3 | 赤口 | 金 | 口舌是非，谨慎行事 |
| 4 | 小吉 | 水 | 小有吉利，渐进成功 |
| 5 | 空亡 | 土 | 谋事落空，徒劳无功 |

- 每个输入数先按 6 取余、余数为 0 按 6 处理；
- 行步规则：`下一宫 = (当前宫编号 + 步数 - 1) mod 6`；第一数从大安起得**天宫**，第二数从天宫续行得**地宫**，第三数从地宫续行得**人宫**；
- 结果区把第三宫作为终落点展示——这是一条产品显示规则，不代表所有教材只断第三宫；
- 注意：知识速查面板中的空亡释义为「事多落空，需防损失」，与运行时的「谋事落空，徒劳无功」不一致（已登记待办 #2）。

### 2. 三种取数方式（V2.2 实现）

| 方式 | 当前实现 |
|---|---|
| 手动输入 | 三个数字输入框；HTML 限制 `min=1 max=999`，输入非数字时提示；负数按绝对值处理 |
| 时间起卦 | 取浏览器当前本地时间：小时 0 → 10，超过 12 减 12；分钟十位与个位分别作为后两数、为 0 时取 10 |
| 随机起卦 | `Math.random()` 生成 1–999 的三个数（无网络、无 `crypto` 调用） |

传统叙述常说「以月、日、时轮数」；V2.2 的「时间起卦」是明确的产品工程实现（小时 + 分钟组合），不应被宣传成古法唯一标准。采用其他教材的农历月日时起法时，可手动输入对应三数。

### 3. 江氏排盘

- **地支轮列**：按当前时辰的阴阳选择序列——阳支「子寅辰午申戌」、阴支「丑卯巳未酉亥」；从时辰在该序列中的位置开始，把六个地支依次映射到六宫；
- **人宫为「我」**：以人宫地支五行为参照，与其他宫位比较得出六亲（自身 / 兄弟 / 子孙 / 父母 / 妻财 / 官鬼）；
- **固定映射**：六神为「青龙、朱雀、勾陈、白虎、玄武、腾蛇」；六星按六宫固定顺序，运行时显示为「木星、火星、土星、金星、水星、天星」（知识速查与测试用「木、火、土、金、水、天」简写，差异见待办 #2）；
- 表格按天 / 地 / 人宫高亮；点击「农历」可打开排盘逻辑详情弹窗。

### 4. 道传排盘

- **只对三宫展开**：读取基础结果的天、地、人三宫，不重新起卦；
- **地支隔位推导**：`地支索引 = (时辰索引 + 2 × 人宫到当前宫位的六宫距离) mod 12`；
- **死六神**（按六宫固定映射）：大安→青龙，留连→勾陈，速喜→朱雀，赤口→白虎，小吉→玄武，空亡→腾蛇；
- **活六神**（随时辰轮转）：顺序固定为「青龙、朱雀、勾陈、白虎、玄武、腾蛇」，青龙起点由时辰决定——子 / 午起大安，丑 / 未起留连，寅 / 申起速喜，卯 / 酉起赤口，辰 / 戌起小吉，巳 / 亥起空亡，再按六宫顺序轮转；
- 说明：V2.2 代码中**没有**「四纵五横」相关实现，道传口径即「死活六神双轨 + 隔位地支」；
- 「死」与「活」是观察层名称，不应理解为现实中的生死断言。

### 5. 结果与记录规则

- 古法 / 江氏 / 道传共用同一组三数、同一问念与同一条记录；切换只改变显示方式；
- 每次打开页面固定回到古法视图（模式持久化未生效，见待办 #1）；
- 与最新一条记录的三数、问念、终卦名全同时合并更新（只刷新模式与时间，不重复入档）。

## 四、问念与断卦思路

1. **定问**：一次只问一件事；明确对象、时间范围与想做的动作（如「未来两周，我是否适合接受这份工作」）；
2. **看盘**：先看三宫顺序与终落宫，再按所选视图读取扩展字段；
3. **解释**：把宫位含义、五行关系、六亲 / 六神 / 六星或死活六神放回问念中，区分「盘面提示」与「现实证据」；
4. **留行动**：给出可在现实中观察或验证的下一步，并事后在历史记录中填写反馈、复盘。

阅读建议：`问念 → 人宫与终落点 → 扩展字段 → 可验证行动`。不建议用多个视图的相似词句「投票」出更确定的答案。

## 五、边界与免责

- 排盘与解卦内容仅为传统民俗参考，**不构成任何预测或决策依据**；
- 涉及健康、财务、法律、安全与重大人生决策时，以可靠信息、专业意见和实际行动为准；
- 不要把「空亡」「赤口」「白虎」等术语直接翻译成现实灾难；不要把「妻财」「官鬼」当作对具体人的身份判定；
- 问念可能包含隐私：本工具不联网、不上传；重要记录请主动导出备份。

## 六、测试与维护口径

- 工程验证回答「代码是否按约定工作」，不证明术数结论正确；
- 当前自动化覆盖：核心计算 5 个脚本 571 项断言、兼容测试 144 用例、受保护包 8 条断言（见[契约测试清单](../质量与审计/契约测试清单.md)）；
- 修改任何排盘规则，必须同步：规则说明（本文 + [docs/版本说明.md](../../docs/版本说明.md)）、测试脚本、必要时提示词与记录结构；
- 新增流派前必须先解决命名、完整规则、样例、测试与回退方式——当前一律不做。
