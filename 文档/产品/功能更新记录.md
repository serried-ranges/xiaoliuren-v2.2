## 一、V2.2.0 功能清单（当前实现，对照源码核对）

| 功能 | 当前实现 | 代码位置 |
|---|---|---|
| 起卦 · 手动输入 | 三个数字输入框（HTML 限制 `min=1 max=999`，`step=1`）；输入 `NaN` 时提示「请填写三个有效的数字」；负数按绝对值处理 | `index.html`、`src/ui/renderer.js`、`src/main.js` |
| 起卦 · 时间起卦 | 取当前本地时间：小时 0 → 10、超过 12 减 12；分钟十位与个位分别为后两数、为 0 时取 10；页面顶部显示时间提示 | `src/main.js` |
| 起卦 · 随机起卦 | `Math.random()` 生成 1–999 的三个数（无网络、无加密 API） | `src/main.js` |
| 古法排盘 | 三数 → 天 / 地 / 人三宫 → 终落宫；结果区展示三宫顺序与终落宫含义 | `src/core/browser-core.js`（运行时） |
| 江氏排盘 | 六宫 + 时辰 → 地支轮列、五行、六亲、六神、六星；含「排盘逻辑详情」弹窗 | `src/core/browser-core.js`、`src/core/calculator.js` |
| 道传排盘 | 天地人三宫 + 时辰 → 隔位排地支、六亲、死六神、活六神 | `src/core/browser-core.js`、`src/core/calculator.js` |
| AI 解析 | 按当前排盘模式生成统一提示词（古法 / 江氏 / 道传），一键复制到外部 AI 工具；本工具不调用模型 | `src/prompts/canonical-prompt.js`、`src/ui/template.js` |
| AI 模板管理 | 3 套默认模板 + 自定义模板的新建 / 编辑 / 删除 / 复制 / JSON 导入导出 | `src/ui/template.js` |
| 历史记录 | 保存、回载、编辑问念（限 50 字）、删除、清空；顶部徽章显示条数 | `src/store/state.js`、`src/ui/renderer.js` |
| 解卦反馈 | 1–5 星准确度评分 + 最多 500 字反馈；支持清除 | `src/ui/feedback.js` |
| 导入 / 导出 | 导出为纯数组 JSON（文件名 `liuShen_export_<时间>.json`）；导入兼容数组、V3.0 / V2.2.1 信封、V2.0 `records/data` 结构 | `src/store/state.js` |
| 身份隔离 | 自动生成 `xll_userId`，历史与模板按身份命名空间隔离 | `src/store/state.js` |
| 知识速查 | 结果区折叠面板：六宫 / 六亲 / 六神 / 六星说明 | `index.html`、`src/ui/renderer.js` |
| 更多菜单 | 导出卦例、导入卦例、切换标准（跳转 `x6ren.cn`）、鸣谢名单、联系作者（点击复制邮箱）、赞助支持 | `index.html`、`src/ui/more.js` |
| PWA 元数据 | manifest 与 apple-touch-icon 内联（`file://` 可用）；**名称残留 V2.1.2，见待办 #3** | `index.html` |

## 二、与 V2.1.2 的差异（V2.2.0 基线，2026-08-13）

| 类型 | 内容 |
|---|---|
| 结构调整 | 单 HTML 拆分为 12 个 JS 模块 + 4 个 CSS；新增单文件打包脚本，交付物仍是单 HTML |
| 新增 | 道传小六壬（死活六神双轨）、3 套 AI 提示词模板、解卦反馈、更多菜单、PWA 元数据、身份隔离与命名空间 |
| 移除 | 收藏夹、时空八字、六十四卦等扩展功能（「简洁优先」定位） |
| 保持不变 | 古法 / 江氏排盘行为、样式与交互 |

## 四、当前取舍

- **不跟进 V3**：V3 的皮肤、免费额度、一键解卦、复杂结果操作均不进入本仓库；
- **算法固定**：古法 / 江氏 / 道传口径冻结，不新增流派；
- **行为差异不隐瞒**：模式持久化失效、六星命名与空亡释义在运行时与知识面板不一致等问题均登记在[待办事项与方案进度](../治理/待办事项与方案进度.md)，修复前不按旧文档描述。
