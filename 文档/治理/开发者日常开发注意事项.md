# 开发者日常开发注意事项（项目级入口）

> 本文只保留最短入口，避免与版本级文档复制同一套命令；完整说明见 [docs/开发者指南.md](../../docs/开发者指南.md)，方向与门槛见[未来发展纲领](未来发展纲领.md)。

## 日常开发

本仓库处于**归档冻结**状态：只修改正确性 / 安全 / 兼容问题，不新增功能。

```powershell
npm ci                  # 首次安装（Vite 等，仅开发/构建用）
npm run check           # 语法检查（12 个模块）
npm run check:docs      # 文档相对链接检查
npm run test:all        # 5 个核心脚本（579 项断言）
npm run test:compat     # V2.2 ↔ V3.0 数据兼容（144 用例）
npm run build           # dist/index.html（可由源码逐字节复现）
npm run build:protected # release/index.html（每次构建字节不同，属正常）
npm run test:protected  # 受保护包检查（8 条断言）
```

提交前至少与 CI 对齐：`check → check:docs → test:all → test:compat → build → build:protected → test:protected`。

## 约束

- 不引入运行时依赖与网络能力；保持 `file://` 直接可用；
- 不改变 `dist/`、`release/` 的生成方式，不手工编辑产物；
- 数据键名与导入导出格式保持兼容；改动前先看 [docs/数据兼容与迁移.md](../../docs/数据兼容与迁移.md)；
- **排盘算法的运行时入口在 `src/core/browser-core.js`**（经 `src/core/domain-adapter.js` 覆盖 `calculator.js` 的同名函数）——只改 `calculator.js` 不会改变页面行为；两处数据副本必须同步（2026-10-01 已统一空亡释义 / 六星命名 / 道传解卦文本）；
- 数字口径（断言数、产物大小）以命令输出为准；变化时同步 [docs/版本说明.md](../../docs/版本说明.md) 与[根 README](../../README.md)；
- 文档修改后运行 `npm run check:docs`；新增文档按[文档/README.md](../README.md)的分层归位；
- 提交信息使用中文 `feat / fix / docs / chore:` 前缀；一次提交只做一类事，纯文档与代码改动分开提交。
